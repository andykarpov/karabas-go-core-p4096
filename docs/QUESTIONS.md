# Вопросы автору Pentagon-4096

Пользователь передаёт их автору (AleksandrDneprCity) вместе с вопросом о лицензии.

1. **Лицензия.** Можно ли сделать FPGA-ядро Pentagon-4096 для плат Karabas Go / Mini / Mini G (открытые исходники, некоммерческий проект) и положить в него BIOS v4.2?
2. **Исходники схемы.** Есть ли схема в текстовом виде (P-CAD ASCII .sch, список цепей)? Бинарный P-CAD 2006 не читается свободными программами, мы разбираем PNG / PDF.
3. **BIOS.** В репозитории `rom_42_release_2026_07_22.bin` 16 КБ, в README — микросхема 64 КБ (3 страницы BIOS + ПЗУ принтера). Где остальные страницы, что в странице принтера?
4. **Порядок битов #7FFD.** README: «бит 7 — 256 КБ, бит 6 — 512 КБ» (KAY + Pent: «бит 6 — 1024, бит 7 — 2048»). На схеме (DD84 / DD86) бит 6 младше бита 7, как в Pentagon-512 / 1024. Верна схема?
5. **384×304 или 384×288?** В README встречаются оба числа. Какая раскладка памяти итоговая — вторая редакция `video_modes.txt` («обнуляем V7, убираем патч A11»)? Подписи «V-верхняя / V-нижняя» там перепутаны?
6. **FlashColor.** Точки INK переключаются между INK и PAPER меандром (/F14 или F7, по вентилям 1:3). Так задумано или должно быть 1:1? Есть фото экрана?
7. **16 colors.** Порядок пикселей в байте (какой — левый: INK D0-D2 + D6 или PAPER D3-D5 + D7) и порядок четырёх областей на экране (4000 / 6000 / C000 / E000 стр. 4).
8. **«Страница 4»** в 512 мультиколор и 16 colors: при экране 7 (#7FFD D3 = 1) берутся данные из страницы 6?
9. **INT.** Точная строка и такт начала INT для Pentagon и фирменного положения, длина INT (сброс по INTA или по `HC`).
10. **Турбо 14 МГц.** Правило WAIT (`WAITP`): на каждое обращение к памяти или только при совпадении с выборкой видео?
11. **Палитра.** Яркость = инверсия записанных бит (выходы К155РУ2), как в ATM Turbo 2+? Пишется ли палитра в TR-DOS (на схеме запрещено, `DOS` = 0)?
12. **Программы.** Какие программы, демо, картинки есть для режимов 512×192, 16 colors, 384×304, FlashColor и для многозадачности? Есть ли тестовые программы режимов?
13. **Порты #3FFD / #5FFD**: используются только для мягкой дешифрации #7FFD в ловушке или у них есть своё назначение?
